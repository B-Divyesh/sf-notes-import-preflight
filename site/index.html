    How it works

    Check the source and destination

    1. 01

      Scan the source

      Save a JSON report before you start the import.

      notes-preflight scan export.zip --json > before.json
    2. 02

      Import a copy

      Keep the original export. Export the destination when the import ends.

      Keep the original unchanged.
    3. 03

      Compare both exports

      Review missing files and changed notes before you accept the move.

      notes-preflight compare before.json after/ --fail-on-loss

    Install from the public source

    Install the command-line tool

    Install Rust 1.82 or newer. Then run this command from any folder.

    Install Rust (external site)

    cargo install --git https://github.com/B-Divyesh/sf-notes-import-preflight.git --locked

    Then run notes-preflight demo. No account or sample download is needed.

    Limits and privacy

    Know what the tool does not do

    • It does not open notes accounts or bypass encryption.
    • It reports proprietary database exports as unsupported.
    • It checks inventory and bytes, not every visual detail.
    • It keeps note bodies and attachment bytes out of saved reports.
